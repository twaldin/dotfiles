# Browser supplements

Use a supplement only for a capability the native browser tool lacks, or where the harness has none.

- **Browser control:** the `agent-browser` skill: a headless CLI any agent runs from a shell on twaldin-home or deckbox, one session per task.
- **Detailed recording:** agent-browser's `trace`, `network har`, `console` and `errors` commands record CDP traces, network and page logs for its own session. Keep recording on demand and store captures with the task, outside shared configuration.

Read a supplement's own instructions only when using it. Follow the host's configured tool restrictions; a fallback is not a way around them.
