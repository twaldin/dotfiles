---
name: computer
description: Desktop tool selection. Use when choosing computer controls or the current harness lacks a needed desktop capability.
---

Prefer computer-use tools supplied by the current harness, following their live documentation. Availability depends on the session, operating system, and granted permissions.

For a missing capability, inspect the machine's configured desktop integration and its documentation. Browser automation supplements control web pages; they do not supply general desktop control. If no suitable tool exists, identify the specific missing capability before adding an integration.

Use the machine that owns the app and its data. Lindy app access stays on the work machine.
